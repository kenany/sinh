# sinh

Calculate the hyperbolic sine of a number.

## Example

```typescript
import { sinh } from 'sinh';

sinh(1);
// => 1.1752011936438014
```

## Installation

``` bash
$ npm install sinh
```

## API

```typescript
import { sinh } from 'sinh';
```

### `sinh(x: number)`

Given a _Number_ `x`, returns the hyperbolic sine of `x` as a _Number_.
